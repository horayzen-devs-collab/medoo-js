      # Sobre o MedooJS

      ## O Que é o MedooJS?
      Inspirado no aclamado [Medoo](https://medoo.in) do PHP, ele actua como uma camada intermediária entre o Node.js e a sua base de dados, sem impedir que você faça o que precisar nesse caminho.

      ## Por que o MedooJS?
      O MedooJS é leve, fácil de usar, fácil de aprender e pensado para o desempenho. Ele se encaixa em qualquer projecto Node.js que dependa de uma base de dados SQL, e ajuda a manter o código de acesso a dados limpo e fácil de perceber.
