  ## Número de registos afetados

  <DocIntro>
    Para obter o número de registos afetados, chama `rowCount()` no valor devolvido por `delete`.
  </DocIntro>

  ```js showLineNumbers
  const result = database.delete("users", {
    type: "business",
    "age[<]": 18
  });

// Devolve o número de registos afetados pela última instrução SQL.
const rowCount = result.rowCount();
  ```
