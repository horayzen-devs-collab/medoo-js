  ## ID do último registo inserido

  <DocIntro>
    Para obter o ID do registo inserido, chama `id()` no valor devolvido por `insert`.
  </DocIntro>

  ```js showLineNumbers
  const returning = database.insert("users", {
    name: "john",
    email: "john@email.com",
    age: 26
  });

  const id = returning.id();
  ```

  <DocIntro>
    Para MSSQL, Oracle e PostgreSQL, indica a chave primária como terceiro parâmetro ao chamar o método `insert`.
  </DocIntro>

  ```js showLineNumbers
  const returning = database.insert("users", {
    name: "john",
    location: "usa"
  }, "id");

  const id = returning.id();
  ```

  ## Inserção múltipla

  <DocIntro>
    Também podes inserir vários registos numa única chamada.
  </DocIntro>

  ```js showLineNumbers
  database.insert("users", [
    {
      name: "john",
      email: "john@email.com",
      age: 26,
      location: "usa"
    },
    {
      name: "doe",
      email: "doe@email.com",
      age: 35,
      location: "china"
    }
  ]);
  ```
