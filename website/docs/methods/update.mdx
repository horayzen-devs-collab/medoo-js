  ## Número de registos afetados

  <DocIntro>
    Para obter o número de registos afetados, chama `rowCount()` no valor devolvido por `update`.
  </DocIntro>

  ```js showLineNumbers
  const result = database.update("users", {
    age: 1
  }, {
    "id[>]": 100
  });

// Devolve o número de registos afetados pela última instrução SQL.
const rowCount = result.rowCount();
  ```
