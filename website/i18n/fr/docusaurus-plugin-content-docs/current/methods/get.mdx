  # Get
  <DocSummary summary="Récupère un seul enregistrement d'une table." />

  <DocSig content="get(table, columns, where)" />

  <DocSig content="get(table, join, columns, where)" />

  ## Valeur de retour

  <DocRet>
    Un objet contenant uniquement les colonnes du premier enregistrement correspondant.
  </DocRet>

  ```js showLineNumbers
  const email = database.get("users", "email", {
    id: 1234
  });

  // Exemple de résultat :
  // "john@email.com"

  const profile = database.get("users", [
    "email",
    "gender",
    "location"
  ], {
    id: 1234
  });

  // Exemple de résultat :
  // {
  //  email: "john@email.com",
  //  gender: "male",
  //  location: "usa"
  // }

  const data = database.get("post", {
    "[>]users": { "author_id": "id" }
  }, [
    "post.content",
    "users.name",
    "users.location"
  ], {
    ORDER: "post.rate"
  });

  // Exemple de résultat :
  // {
  //  content: "John was here.",
  //  name: "john",
  //  location: "usa"
  // }
  ```
