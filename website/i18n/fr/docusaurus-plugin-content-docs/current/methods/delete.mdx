  ## Nombre de lignes affectées

  <DocIntro>
    Pour obtenir le nombre de lignes affectées, appelle `rowCount()` sur la valeur renvoyée par `delete`.
  </DocIntro>

  ```js showLineNumbers
  const result = database.delete("users", {
    type: "business",
    "age[<]": 18
  });

// Renvoie le nombre de lignes affectées par la dernière instruction SQL.
const rowCount = result.rowCount();
  ```
