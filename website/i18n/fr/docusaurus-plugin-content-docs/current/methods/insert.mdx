  ## ID du dernier enregistrement inséré

  <DocIntro>
    Pour obtenir l'ID de l'enregistrement inséré, appelle `id()` sur la valeur renvoyée par `insert`.
  </DocIntro>

  ```js showLineNumbers
  const returning = database.insert("users", {
    name: "john",
    email: "john@email.com",
    age: 26
  });

  const id = returning.id();
  ```

  <DocIntro>
    Pour MSSQL, Oracle et PostgreSQL, indique la clé primaire comme troisième paramètre lors de l'appel de la méthode `insert`.
  </DocIntro>

  ```js showLineNumbers
  const returning = database.insert("users", {
    name: "john",
    location: "usa"
  }, "id");

  const id = returning.id();
  ```

  ## Insertion multiple

  <DocIntro>
    Tu peux également insérer plusieurs lignes en un seul appel.
  </DocIntro>

  ```js showLineNumbers
  database.insert("users", [
    {
      name: "john",
      email: "john@email.com",
      age: 26,
      location: "usa"
    },
    {
      name: "doe",
      email: "doe@email.com",
      age: 35,
      location: "china"
    }
  ]);
  ```
