  ## Nombre de lignes affectées

  <DocIntro>
    Pour obtenir le nombre de lignes affectées, appelle `rowCount()` sur la valeur renvoyée par `update`.
  </DocIntro>

  ```js showLineNumbers
  const result = database.update("users", {
    age: 1
  }, {
    "id[>]": 100
  });

// Renvoie le nombre de lignes affectées par la dernière instruction SQL.
const rowCount = result.rowCount();
  ```
