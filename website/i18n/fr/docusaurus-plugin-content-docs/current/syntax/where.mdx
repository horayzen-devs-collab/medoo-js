  # Syntaxe WHERE

  <DocIntro>
    Certaines méthodes de MedooJS acceptent un argument `where` pour filtrer les enregistrements, comme la clause WHERE de SQL. Bien que les conditions SQL puissent devenir complexes et présenter des risques d'injection SQL lorsqu'elles sont écrites manuellement, MedooJS fournit une manière structurée et expressive de construire des clauses WHERE en toute sécurité.
  </DocIntro>

  ## Conditions de base

  <DocIntro>
    Les conditions de base sont simples à utiliser. Tu peux également ajouter des opérateurs au nom d'une colonne pour créer des comparaisons plus avancées, notamment pour les valeurs numériques.
  </DocIntro>

  ```js showLineNumbers
  database.select('users', 'username', {
    email: 'john@doe.com'
  });
  // WHERE email = 'john@doe.com'

  database.select('users', 'username', {
    id: 200
  });
  // WHERE id = 200

  database.select('users', 'username', {
    'id[>]': 200
  });
  // WHERE id > 200

  database.select('users', 'username', {
    'id[>=]': 200
  });
  // WHERE id >= 200

  database.select('users', 'username', {
    'id[!]': 200
  });
  // WHERE id != 200

  database.select('users', 'username', {
    'age[<>]': [200, 500]
  });
  // WHERE age BETWEEN 200 AND 500

  database.select('users', 'username', {
    'age[><]': [200, 500]
  });
  // WHERE age NOT BETWEEN 200 AND 500
  ```

  <DocIntro>
      Les opérateurs `<>` et `><` peuvent également être utilisés avec des valeurs de date et d'heure.
  </DocIntro>

  ```js showLineNumbers
  database.select('users', 'username', {
    'created_at[<>]': [new Date(2024, 0, 1).toISOString().split('T'), new Date().toISOString().split('T')]
  });
  // WHERE ("created_at" BETWEEN '2024-01-01' AND '2026-01-01')

  database.select('users', 'username', {
    'created_at[><]': [new Date(2024, 0, 1).toISOString().split('T'), new Date().toISOString().split('T')]
  });
  // WHERE ("created_at" NOT BETWEEN '2024-01-01' AND '2026-01-01')
  ```

  <DocIntro>
      Tu peux transmettre non seulement une valeur textuelle ou numérique unique, mais aussi un tableau. Dans ce cas, Medoo génère une condition IN.
  </DocIntro>

  ```js showLineNumbers
  database.select('users', 'username', {
    OR: {
      id: [3, 616, 217, 56],
      email: ['john@doe.com', 'lion@king.com', 'master@medoo.js']
    }
  });
  // WHERE id IN (3, 616, 217, 56) OR email IN ('john@doe.com','lion@king.com','master@medoo.js')
  ```

  ## Conditions négatives

  <DocIntro>
      Utilise l'opérateur `!` pour construire des comparaisons négatives telles que !=, NOT IN et IS NOT NULL.
  </DocIntro>

  ```js showLineNumbers
  database.select('users', 'user_name', {
    'username[!]': 'john',
    'id[!]': 616,
    'email[!]': ['john@doe.com', 'lion@king.com', 'master@medoo.js'],
    'city[!]': null,
    'promoted[!]': true
  });
  // WHERE
  // username != 'john' AND
  // id != 616 AND
  // email NOT IN ('john@doe.com', 'lion@king.com', 'master@medoo.js') AND
  // city IS NOT NULL AND
  // promoted != 1
  ```

  <DocIntro>
      Tu peux également utiliser le résultat des méthodes `select` ou `get` comme valeur d'une condition.
  </DocIntro>

  ```js showLineNumbers
  database.select('users', 'username', {
    id: database.select('post', 'user_id', {
      'comments[>]': 60
    })
  });
  // WHERE id IN (3, 56, 132, 4133)
  ```

  ## Conditions logiques

  <DocIntro>
    Les conditions logiques décrivent les relations entre plusieurs expressions. Utilise `AND`/`OR` pour construire des requêtes plus complexes.
  </DocIntro>

  ### Utilisation de base

  ```js showLineNumbers
  // MedooJS combine les conditions avec `AND` par défaut.
  database.select('users', 'username', {
    'id[>]': 150,
    'age[<>]': [18, 25],
    gender: 'male'
  });
  // WHERE id > 150 AND age BETWEEN 18 AND 25 AND gender = 'male'

  database.select('users', 'username', {
    OR: {
      'user_id[<]': 150,
      'age[<>]': [18, 25],
      gender: 'female'
    }
  });
  // WHERE user_id < 150 OR age BETWEEN 18 AND 25 OR gender = 'female'
  ```

  ### Conditions imbriquées

  ```js showLineNumbers
  database.select('users', '*', {
    AND: {
      OR: {
        username: 'john',
        email: 'john@doe.com'
      },
      password: 'adbcde'
    }
  });
  // WHERE (username = 'john' OR email = 'john@doe.com') AND password = 'adbcde'
  ```

  ## Conditions LIKE
  <DocIntro>
      Utilise l'opérateur `~` pour construire des conditions `LIKE`. Il peut être utilisé aussi bien dans les conditions de base que dans les conditions logiques.
  </DocIntro>

  ```js showLineNumbers
  database.select('users', 'id', {
    'hobby[~]': '%ball'
  });
  // WHERE hobby LIKE '%ball'
  ```

  ### Correspondance de groupe

  ```js showLineNumbers
  database.select('users', 'id', {
    'hobby[~]': ['%ball', '%ing', 'ball%']
  });
  // WHERE hobby LIKE '%ball' OR hobby LIKE '%ing' OR hobby LIKE 'ball%'
  ```

  ### Conditions LIKE négatives

  ```js showLineNumbers
  database.select('users', 'id', {
    'hobby[!~]': '%ball'
  });
  // WHERE hobby NOT LIKE '%ball'
  ```

  ### Conditions LIKE composées

  ```js showLineNumbers
  // MedooJS combine les conditions `LIKE` avec `OR` par défaut.
  // La requête ci-dessous montre comment les combiner avec `AND`. 
  database.select('users', 'id', {
    'hobby[~]': { AND: ['%ball', '%o%'] }
  });
  // WHERE hobby LIKE '%ball' AND hobby LIKE '%o%'
  ```

  ### Caractères génériques SQL

  <DocIntro>
      Tu peux utiliser les modèles de caractères génériques SQL pour effectuer des recherches plus avancées.
  </DocIntro>

  ```js showLineNumbers
  database.select('users', 'id', {
    'city[~]': '%stan' // Kazakhstan, Uzbekistan, Turkmenistan, ...
  });

  database.select('users', 'id', {
    'city[~]': 'Londo_' // London, Londox, Londos, ...
  });
  ```

  ## Conditions de tri

  <DocIntro>
      Utilise `ORDER` pour trier l'ensemble des résultats.
  </DocIntro>

  ```js showLineNumbers
  // Trier selon une seule colonne.
  database.select('users', 'id', {
    ORDER: 'id'
  });

  // Trier selon plusieurs colonnes en utilisant le sens par défaut.
  database.select('users', 'id', {
    ORDER: ['id', 'username']
  });

  // Trier selon plusieurs colonnes.
  database.select('users', 'id', {
    ORDER: {
      // Trier une colonne selon un ordre personnalisé.
      id: [34, 21, 75, 89, 414, 3],

      // Tri décroissant.
      username: 'DESC',

      // Tri croissant.
      email: 'ASC'
    }
  });
  ```

  ## Expressions régulières

  <DocIntro>
      Utilise l'opérateur `REGEXP` pour comparer des valeurs à une expression régulière.
  </DocIntro>

  ```js showLineNumbers
  database.select('users', '*', {
    'username[REGEXP]': '[a-z0-9]*',
    'email[!REGEXP]': '[0-9]*'
  });
  // WHERE username REGEXP '[a-z0-9]*' AND email NOT REGEXP '[0-9]*'
  ```

  ## LIMIT et OFFSET

  <DocIntro>
      Utilise `LIMIT` pour limiter le nombre de lignes renvoyées. Tu peux également spécifier un `OFFSET`.
  </DocIntro>

  ```js showLineNumbers
  // Renvoyer les 50 premières lignes.
  database.select('users', 'id', {
    LIMIT: 50
  });

  // Ignorer les 15 premières lignes, puis renvoyer les 50 suivantes.
  database.select('users', 'id', {
    LIMIT: [15, 50]
  });

  // Pour `Oracle` et `MSSQL`, un `ORDER` est également requis.
  database.select('users', 'id', {
    LIMIT: [15, 50],
    ORDER: 'created_at'
  });
  ```
