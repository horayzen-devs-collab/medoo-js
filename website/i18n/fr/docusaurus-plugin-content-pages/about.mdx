      # À propos de MedooJS

      ## Qu’est-ce que MedooJS ?
      Inspiré du célèbre [Medoo](https://medoo.in) pour PHP, il agit comme une couche intermédiaire entre Node.js et votre base de données, sans vous empêcher de faire ce dont vous avez besoin en cours de route.

      ## Pourquoi MedooJS ?
      MedooJS est léger, facile à utiliser, facile à apprendre et conçu pour la performance. Il s’intègre à tout projet Node.js qui repose sur une base de données SQL et aide à garder le code d’accès aux données propre et facile à comprendre.
