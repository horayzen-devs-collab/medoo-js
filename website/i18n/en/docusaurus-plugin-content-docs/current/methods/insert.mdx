  # Insert
  <DocSummary summary="Insert one or more records into a table." />
  
  <DocSig content="insert(table, values)" />

  <DocParams>
    <ParamsItem title="table [string]">
      The name of the table.
    </ParamsItem>

    <ParamsItem title="values [object]">
      The data to be inserted.
    </ParamsItem>
  </DocParams>

  ## Last Insert ID

  <DocIntro>
    To get the inserted row ID, call `id()` on the `insert` returned value.
  </DocIntro>

  ```js showLineNumbers
  const returning = database.insert("users", {
    name: "john",
    email: "john@email.com",
    age: 26
  });

  const id = returning.id();
  ```

  <DocIntro>
    For MSSQL, Oracle and PostgreSQL, provide the primary key as the third parameter when calling `insert` method.
  </DocIntro>

  ```js showLineNumbers
  const returning = database.insert("users", {
    name: "john",
    location: "usa"
  }, "id");

  const id = returning.id();
  ```

  ## Multi-insertion

  <DocIntro>
    You can also insert multiple rows in a single call.
  </DocIntro>

  ```js showLineNumbers
  database.insert("users", [
    {
      name: "john",
      email: "john@email.com",
      age: 26,
      location: "usa"
    },
    {
      name: "doe",
      email: "doe@email.com",
      age: 35,
      location: "china"
    }
  ]);
  ```
