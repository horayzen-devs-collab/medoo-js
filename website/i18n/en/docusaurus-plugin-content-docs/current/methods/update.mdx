  # Update
  <DocSummary summary="Update records in a table." />
  
  <DocSig content="update(table, data, where)" />

  <DocParams>
    <ParamsItem title="table [string]">

    </ParamsItem>

    <ParamsItem title="data [object]">
      The column-value entries to update.
    </ParamsItem>

    <ParamsItem title="where [object] (optional)">
      The WHERE clause used to filter the records to be updated.
    </ParamsItem>
  </DocParams>

  ## Affected Rows Count

  <DocIntro>
    To get the affected rows count, call `rowCount()` on the `update` returned value.
  </DocIntro>

  ```js showLineNumbers
  const result = database.update("users", {
    age: 1
  }, {
    "id[>]": 100
  });
 
// Returns the number of rows affected by the last SQL statement.
const rowCount = result.rowCount();
  ```
