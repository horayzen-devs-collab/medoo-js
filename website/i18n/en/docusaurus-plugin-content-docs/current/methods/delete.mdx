  ## Affected Rows Count

  <DocIntro>
    To get the affected rows count, call `rowCount()` on the `delete` returned value.
  </DocIntro>

  ```js showLineNumbers
  const result = database.delete("users", {
    type: "business",
    "age[<]": 18
  });
 
// Returns the number of rows affected by the last SQL statement.
const rowCount = result.rowCount();
  ```
