  # Get
  <DocSummary summary="Retrieve a single record from a table." />
  
  <DocSig content="get(table, columns, where)" />
  
  <DocSig content="get(table, join, columns, where)" />
  
  ## Return Value

  <DocRet>
    An object containing only the columns of the first matching record.
  </DocRet>

  ```js showLineNumbers
  const email = database.get("users", "email", {
    id: 1234
  });
   
  // Example result:
  // "john@email.com"
   
  const profile = database.get("users", [
    "email",
    "gender",
    "location"
  ], {
    id: 1234
  });
   
  // Example result:
  // {
  //  email: "john@email.com",
  //  gender: "male",
  //  location: "usa"
  // }
   
  const data = database.get("post", {
    "[>]users": { "author_id": "id" }
  }, [
    "post.content",
    "users.name",
    "users.location"
  ], {
    ORDER: "post.rate"
  });
   
  // Example result:
  // {
  //  content: "John was here.",
  //  name: "john",
  //  location: "usa"
  // }
  ```
