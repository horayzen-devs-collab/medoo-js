      # About MedooJS

      ## What is MedooJS?
      Inspired by the acclaimed PHP [Medoo](https://medoo.in), it acts as an intermediary layer between Node.js and your database, without preventing you from doing whatever you need along the way.

      ## Why MedooJS?
      MedooJS is lightweight, easy to use, easy to learn, and designed for performance. It fits into any Node.js project that relies on an SQL database, and helps keep data access code clean and easy to understand.
